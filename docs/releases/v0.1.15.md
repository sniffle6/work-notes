## Highlights

- "Create Jira ticket" on a note now has the Jira agent write the ticket for you, and you can ask it for changes before anything is created.
- A note links to the tickets made from it: click the ticket key to open it.
- Cancel a parse that is queued or running.

## Changes

### Jira

- "Create Jira ticket" on a note opens the new-ticket form with the agent beside it. The agent turns the note into a ticket: a clear summary, a description, and an issue type.
- Ask the agent to rework the draft in plain words, or edit the form yourself. The agent sees your edits. Nothing is in Jira until you press "Create ticket".
- The agent can rework a draft started with "New ticket" too.
- After you create a ticket, the Jira view stays on it, even before your filter lists it.
- The note shows its new ticket key straight away. Clicking a ticket key on a note opens that ticket in the Jira view.

### Notes

- The "Queued for parsing" and "Parsing in background" banner has a Cancel button. Cancelling a reparse keeps the note as it was. Cancelling a note's first parse leaves it marked as cancelled with a Retry button.
- Cancelling, or a parse timing out, now fully stops the Codex process instead of leaving it running in the background.

## Install And Update Notes

- Windows installer is attached to the GitHub release.
- Existing installs update from the latest-release `latest.json` after publish.
- Drafting a ticket with the agent runs through your local Codex CLI, the same way note parsing does.
