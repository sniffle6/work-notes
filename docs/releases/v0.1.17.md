## Highlights

- Find every ticket with unfinished writing using the new "Has drafts" filter.
- See all Jira changes waiting for your approval in one list, across every agent conversation.
- The Jira filter bar no longer shows a stray vertical scrollbar.

## Changes

### Ticket Drafts

- Ticket rows mark "Unsent comment" and "Edit in progress" so unfinished writing is visible in the list.
- "Has drafts" shows only tickets with an unsent comment or an open edit, with a count of how many there are.
- Drafts on tickets outside the current filter appear under "Outside this ticket list". Search narrows them by key and title, and the ticket loads when you open it.
- The new-ticket draft stays separate and is still reached through "Resume draft".

### Pending Approvals

- The Agent button shows how many proposed Jira changes are waiting for approval.
- The agent pane lists pending approvals oldest first, with the conversation each one belongs to. Selecting one opens that conversation at the exact proposal.
- Approval still happens on the proposal's own review. Resolved proposals leave the list but stay in the conversation history.
- If the list cannot be refreshed, Work Notes keeps the last known list, warns that it may be out of date, and offers a retry.

### Jira Layout

- Ticket rows have dividers and more spacing, and status groups are separated, for easier scanning.
- Filter tabs now fit inside the header, which removes a vertical scrollbar on the filter bar. Extra filters remain reachable by scrolling sideways.

## Install And Update Notes

- Windows installer is attached to the GitHub release.
- Existing installs update from the latest-release `latest.json` after publish.
