## Highlights

- Tickets and ticket lists open at once from a saved copy while Jira loads the current version.
- Descriptions and comments are written in Markdown, and formatting such as bold, links, nested lists, and tables survives an edit.
- The ticket search box can search all of Jira, not just the tickets already listed.
- Saving an edit, or approving an agent's change, no longer overwrites a change someone else made in Jira in the meantime.

## Changes

### Saved Copies

- The Jira view shows the tickets and ticket lists Jira last returned while it asks Jira for current ones. The header says "Refreshing tickets" and marks a saved copy.
- A saved copy is read-only. Assign, edit, move, and comment wait until Jira's current version arrives.
- A ticket that was deleted, or that your account can no longer see, is removed from the view and from the saved copies.
- Saved copies are kept per Jira site and account. Switching either never shows the other's tickets.

### Markdown Descriptions And Comments

- Bold, italics, strikethrough, inline code, links, nested and numbered lists, and tables turn into Jira formatting and back again without loss.
- Characters that look like formatting in plain text are kept as typed.
- The ticket pane renders the same Markdown, including links, nested lists, and numbered lists that start past 1.

### Search All Of Jira

- Press Enter in the search box, or choose the Search button under the results, to search the text of every ticket in the project, newest first.
- The search appears as a removable "Search:" tab.

### Edit Conflicts

- An edit remembers the summary and description it started from, even across restarts.
- Only fields you changed are saved. Editing just the description no longer resends an older summary.
- If Jira changed a field you are saving since your edit started, nothing is saved. Your text stays in the form, with Jira's current version beside it, and "Save anyway" replaces it with your changes.
- Approving an agent's proposed change checks the ticket first. If the summary, description, status, or assignee it changes was changed in Jira since the proposal, the proposal fails without writing, and you can ask the agent to propose it again.

## Install And Update Notes

- Windows installer is attached to the GitHub release.
- Existing installs update from the latest-release `latest.json` after publish.
- An edit left unfinished in an earlier version has no recorded starting point. Its first save reports a conflict, and "Save anyway" saves all of its text.
