## Highlights

- Saving a note is faster. Each save now appends to a log file instead of rewriting a journal, and it is still flushed to disk at once.
- Editing, parsing, and capturing notes no longer slow down as your notebook grows.

## Changes

### Faster Saves

- The notes database uses a write-ahead log, so each save writes less to disk.
- Every save is still flushed to disk before it finishes, so a saved note survives a power cut.

### Search Index Updates

- Updating a note's search entry now takes about the same time however many notes you have. It no longer reads the whole search index.
- The first start after updating prepares the search index once. It also removes duplicate entries and entries left behind by deleted notes.

## Install And Update Notes

- Windows installer is attached to the GitHub release.
- Existing installs update from the latest-release `latest.json` after publish.
- The database now has two companion files, `work-notes.sqlite3-wal` and `work-notes.sqlite3-shm`. To back up your notes, close Work Notes and copy every `work-notes.sqlite3*` file in `%APPDATA%\aweber\Work Notes\data`.
