## Highlights

- Sidebar badges and the inbox load with much less work, which keeps large workspaces responsive.
- Parse status updates as soon as a parse starts or finishes, instead of up to 5 seconds later.
- Search runs once you pause typing, and the results always match the text you typed last.

## Changes

### Sidebar And Inbox

- Sidebar badge counts come from the database. The app no longer loads the inbox, suggested actions, and follow-ups just to count them.
- Badge counts are now exact. Before, a workspace with more than 1,000 notes or 500 actions showed capped counts.
- The inbox and follow-up lists load the tags of all listed notes at once instead of one note at a time.

### Parsing

- The main window refreshes when a parse starts or finishes, instead of checking every 5 seconds.
- A check every 30 seconds remains as a fallback.
- Refresh requests that arrive while one is running are combined into a single follow-up refresh.

### Search

- Typing in the search box searches once you pause for 150 ms, not on every keystroke. Other filters still apply at once.
- A slow answer for earlier search text can no longer replace the results, or show an error, for text you typed later.

## Install And Update Notes

- Windows installer is attached to the GitHub release.
- Existing installs update from the latest-release `latest.json` after publish.
