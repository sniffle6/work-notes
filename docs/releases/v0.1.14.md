## Highlights

- Work Jira tickets inside Work Notes: see what needs doing, open a ticket, move it, comment, edit, and create new ones.
- Ask a Jira agent in plain words. "Show me the important tickets I need to take care of today" puts those tickets in the list.
- A lighter, cleaner interface across the app, with panels you can collapse.
- Describe a colour theme in Settings and have it built for you.

## Changes

### Jira

- Added a Jira view with a ticket list grouped by status, a search box, and filters for your open tickets, all open tickets, and unassigned tickets. Add your own JQL filters in Settings > Jira.
- A ticket shows its description and comments, with one-click status moves, comments, edits, and "Assign to me".
- "Copy agent prompt" copies a ticket's details as a ready-made prompt for a coding agent.
- "Create Jira ticket" on a note starts a ticket from that note and keeps the ticket key linked to it.
- The Jira agent can put a set of tickets in the list, open a ticket, and look things up on its own. Anything that changes Jira is shown as a proposal and runs only after you approve it. Conversations are saved.

### Follow-ups

- The page now leads with what is left to do, with counts for overdue, blocked, and waiting items.
- Finished follow-ups are hidden until you choose "Show done".
- Each follow-up shows its owner, due date, and source note. Lanes with overdue or blocked work come first.
- "Drop" removes a follow-up that no longer matters without marking it done. "Drop all" clears a lane.

### Appearance

- Lighter type and far fewer boxes and borders throughout the app.
- The note toolbar stays on one line at any window width.
- Collapse the sidebar with its button or Ctrl+B. In the Jira view, `[` toggles the ticket list and `]` toggles the agent. Suggested actions collapse from their header. Each choice is remembered.
- Settings > Appearance lists every theme in one place. Everforest Dark and Everforest Light are now separate entries, replacing the Dark/Light switch.
- "Build a theme" turns a description into a full colour theme, previews it across the app, and lets you ask for changes before you keep it. Themes you keep can be deleted later.
- A line of dashes in a note now renders as a divider.

## Install And Update Notes

- Windows installer is attached to the GitHub release.
- Existing installs update from the latest-release `latest.json` after publish.
- Jira is optional. To use it, set the `JIRA_EMAIL` and `JIRA_API_TOKEN` environment variables, restart Work Notes, then enter your Jira site URL and project key in Settings > Jira. The API token is read from the environment and is never stored by Work Notes.
- The Jira agent and the theme builder run through your local Codex CLI, the same way note parsing does.
